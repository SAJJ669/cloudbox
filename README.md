# CloudBox

CloudBox is a web application that allows users to upload, share, and manage their files securely using Supabase.  

## Features
- User authentication with Supabase
- File upload and download
- Generate shareable public links
- Responsive design

## Technologies Used
- Supabase Storage & Auth
- Tailwind CSS
- TypeScript

## How to Run
1. Clone the repository: `git clone https://github.com/SAJJ669/cloudbox.git`
2. Install dependencies: `npm install`
3. Run the app: `npm run dev`
